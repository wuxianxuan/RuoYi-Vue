# 趋势上涨选股 + 积累池减法 + 日推荐 说明文档

> 本文档存档两个定时任务的最终设计、配置、逻辑与回测结论，供后续迭代参考。

## 一、两个任务的分工

```
交易日 16:40  stockRisingTrendTask（趋势上涨选股）
                ↓ 命中「突破箱体后的上升趋势」的股票
        累加进「趋势上涨选股」积累分组 + 记录 low_date 到 stock_rising_low 表
                ↓
交易日 16:50  stockDayTradingTask（积累池减法 + 日推荐）
                ↓ 读积累分组和 low_date
        ① 走下坡（当天收盘 < low_date 收盘价）→ 移出积累池
        ② 最近走弱（连跌/跌破前天开盘）→ 不进当日推荐（但留池）
        ③ 换手率 < 8% → 不进当日推荐（但留池）
                ↓
        生成「趋势上涨选股_日期」日推荐分组（用户次日实际使用的数据）
```

**核心分工**：积累池负责「撒网早期捕获趋势」（广度），日推荐负责「趋势+换手率精选」（精度）。

## 二、最终配置（application.yml）

```yaml
stock:
  rising-trend:            # 进池判定
    lookback-days: 30      # 回看日历天数
    min-klines: 15         # 最少K线数
    min-low-days: 5        # 低点到最新最少根数
    min-gain: 5.0          # 整体涨幅≥5%（突破箱体）
    near-high: 0.9         # 贴近阶段新高（未大幅回落）
    local-low-window: 3    # 局部低点（回调谷）识别窗口
    exclude-st: true       # 排除 ST
    markets: SH,SZ         # 扫描市场
    exclude-code-prefixes: 300,301,688,689  # 排除创业/科创
    group-name: 趋势上涨选股
  day-trading:             # 出池+日推荐
    lookback-days: 7       # 最近趋势回看
    min-turnover-rate: 8.0 # 换手率≥8% 才进日推荐
```

## 三、stockRisingTrendTask 进池逻辑（analyze）

对每只股票，回看 30 日历天日K线，判定：

1. K线数 ≥ minKlines(15)。
2. 找窗口内最低收盘日 minIdx 作为趋势起点。
3. 切片 [minIdx, 最新] 至少 minLowDays(5) 根K线。
4. **整体涨幅**：(最新 - 最低)/最低 ≥ minGain(5%)，识别突破箱体的上升趋势。
5. **贴近新高**：最新 ≥ 阶段最高收盘 × nearHigh(0.9)，过滤涨后跌回箱体的假突破。
6. 记录 **low_date = 最近局部低点（回调谷）**，而非全局最低点。

**命中后**：累加进「趋势上涨选股」分组（去重），low_date 写入 stock_rising_low 表（INSERT IGNORE 同股票同日期去重）。

**支持日期入参**：`stockRisingTrendTask.execute(日期)`，为空默认当天。

## 四、stockDayTradingTask 出池+日推荐逻辑

1. 读「趋势上涨选股」分组内股票，及每只股票最近 low_date（`selectLatestLowWithClose` 取 max(low_date)）。
2. 逐只判定：
   - **走下坡**：当天收盘 < low_date 收盘价 → 移出积累池（趋势已断）。
   - **最近走弱**：最近两日连续下跌，或当前价 < 前天开盘价 → 不进当日推荐（但留池）。
   - **流动性**：换手率 < 8% → 不进当日推荐（但留池）。
3. 生成「趋势上涨选股_日期」日推荐分组（幂等，同名已存在则跳过）。

**支持日期入参**：`stockDayTradingTask.execute(日期)`，为空默认当天。

## 五、关键设计结论（为什么这么设计）

1. **进池用「整体涨幅+贴近新高」，不用「平滑上涨」**：原逻辑要求「连续阳线无回调 + 无涨停」，会漏掉「深跌后反转 + 涨停加速」的强势股（如福建水泥 7-22 见底后回调 -2.99% 就被过滤）。
2. **low_date 记「最近局部低点」，不用「全局最低点」**：上涨中 low_date 随平台低点抬高，跌破最近平台即触发删除，比跌破全局低点更及时（见顶后回吐更少）。
3. **日推荐用「换手率≥8%」精选**：换手率是区分「妖股(活跃) vs 僵尸蓝筹(冷门) vs 超跌反弹」的最有效指标。成交额、量比与换手率高度相关，属冗余，已去掉。
4. **积累池宽松、日推荐严格**：进池门槛低（min-gain=5%）保证早期捕获；日推荐两道过滤（趋势+换手率）保证精度。

## 六、回测验证数据（2026-07-23 ~ 2026-10-23，全市场沪深）

- 积累池：**703 只**（min-gain=5%）。
- 日推荐（趋势过滤 isRecentWeak）：最后一天 417 只。
- 日推荐（+ 换手率≥8%）：**最后一天 89 只，日均 63 只**。

目标股验证（5 只「深跌反转」样本：福建水泥/远东股份/新亚制程/通达创智/百亚股份）：
- 5 只均能在初期（7月底~8月）进池。
- 见顶暴跌的（远东/新亚/通达）被「走下坡」正确止损；福建水泥、百亚股份在最后一天日推荐中。

## 七、调参指南

| 参数 | 含义 | 调大 | 调小 |
|---|---|---|---|
| min-gain | 进池整体涨幅门槛 | 池子更净、发现更晚 | 池子更宽、发现更早 |
| near-high | 贴近新高的比例 | 更严格（不容回落） | 更宽松 |
| local-low-window | 局部低点窗口 | 更稳（容忍大回调） | 更敏感（小回调即换低点） |
| min-turnover-rate | 日推荐换手率门槛 | 日推荐更少更精 | 日推荐更多 |

## 八、后续迭代

> 后续若提供新的目标股票走势，将对照本文档修正这两个定时任务的逻辑，使其更符合选股目的。当前版本：min-gain=5% + 换手率≥8% + 局部低点，已验证可捕获「深跌反转」类强势股。
